# Clothing-Classification-Using-Neural-Networks

## Dataset

This project uses the **Fashion-MNIST** dataset (CSV format). Due to file size limits, the data is not included in this repository.

1. Download the dataset from Kaggle: [Fashion-MNIST Dataset](https://www.kaggle.com/datasets/zalando-research/fashionmnist)
2. Extract the `.zip` file and place `fashion-mnist_train.csv` and `fashion-mnist_test.csv` in the project's root directory.
